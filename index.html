Principles in practice

Why people choose RootRecord.

⌂

On your machine

Your primary database is a file on your PC. Back it up like any other important file — or let the app run scheduled local backups.

⊙

Offline-first

Core workflows never depend on a connection. Sign-in, sync, and cloud backup are used only when you enable them.

Σ

Honest totals

Hours worked, categories, exports — numbers reconcile by design. No surprises when it's time for reports and invoices.

⇅

Optional cloud

A clean path to subscription, sync, and secure online backup. One account across RootRecord apps when you want it.

↻

Regular updates

Signed Windows installers on GitHub Releases. Each build is noted so you always know what's running.
